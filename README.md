## About

This package provided pre-configured rulesets for **PHP_CodeSniffer** and **PHPStan** to help maintain consistent code quality across PHP projects. It included ready-to-use configurations created by Contributte authors.

## Usage

To install the latest version of `contributte/code-rules`:

```bash
composer require --dev contributte/code-rules
```

## Configuration Files

The package included:

- **PHPStan configuration** (`paveljanda/phpstan.neon`) - Static analysis rules
- **CodeSniffer ruleset** (`paveljanda/ruleset.xml`) - Coding standard rules
